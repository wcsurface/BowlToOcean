Bowl to Ocean Aquarium Sim

A native Android aquarium simulation & progression game powered by 100% Jetpack Compose and hardware-accelerated 2D mesh skinning.

Explore Features

Engine & Gameplay Architecture

2D Mesh Skinning Engine

Zero heavy external game engines. Built with pure Jetpack Compose Canvas.drawVertices() 2D mesh deformation delivering fluid 60 FPS swimming sine waves and 250ms smooth direction flips.

7 Tank Progression Tiers

Progress from a 10-gallon Desktop Bowl to an Oceanic Mega-Tank with 1,000-gallon capacity, custom maintenance actions, and ambient atmospheric water caustics.

14 Species & Autonomous AI

Features 14 aquatic species with custom swimming speeds, wave frequencies, and schooling boids algorithms (separation, alignment, cohesion) plus glass-tap reactivity.

Cloud Sync & Live Economy

DataStore local persistence coupled with lightweight cloud state synchronization and remote-tunable game balance parameters.
